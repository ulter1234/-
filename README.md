# 课程大作业项目 

>  **项目声明**：本项目为作者的课程作业，主要用于结课考核、学术成果展示与代码托管。

---

##  技术栈与环境
* **开发语言**: Python 
* **硬件环境**: NVIDIA RTX 4060 GPU


##  功能特点
* **特性 1**: 本项目实现了针对伪随机数序列的五项基础统计测评（频数、间
隙、游程、二维扑克、块内频数），以及符合 NIST SP 800-22 国际标准的单比特
频数、块内频数和游程测试。支持百万级大样本的高速计算与卡方（χ2）统计量
自动化输出。
* **特性 2**：设计并实现了两种高质量的随机数生成函数：一是基于连
续映射的无偏差 [0, N − 1] 离散均匀分布函数；二是基于 Box-Muller 变换的标准
正态分布生成函数。性能方面借助于底层矢量化运算技术，本项目能够在 1 秒内完成对 106 规模样本的
生成、二值化转换与全套统计学检验，具备高执行效率。
